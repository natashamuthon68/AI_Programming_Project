## Project Title
AKAZA - Adaptive Knowledge and AI Zone Assistant

## What This Project Is About
This is a simple chatbot i built using Python named AKAZA 
(Adaptive Knowledge and AI Zone Assistant). It answers common 
questions about Artificial Intelligence and Africa International 
University using if-else logic and keyword matching. It can handle 
5 different user intents and gives polite, informative responses 
each time.


## Libraries I Used
- `re` — for detecting keywords in user input
- `sys` — for handling the exit command cleanly
- `random` — to vary responses so the chatbot doesn't repeat itself
- `string` — to clean up user input before processing it

## How to Run It
1. Make sure you have Python 3 installed
2. Clone the repo:
   git clone https://github.com/natashamuthon68/AI_Programming_Project
3. Open the project folder:
   cd AI_Programming_Project
4. Run the chatbot:
   python chatbot.py
5. Type any question about AI or AIU and the bot will respond
6. Type 'bye' to exit the chatbot
